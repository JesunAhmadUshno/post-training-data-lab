# Level 2, Build: post-training-data-lab

Status: DONE (Build, v0.5, 2026-11-05). A seeded synthetic data
generator, filtering through the Level 1 Learn pipeline, and a
data mixture study with a measured downstream effect. All data
is synthetic, generated by this project, and labelled synthetic
in every file. No real data was used, downloaded, or claimed.

## Summary

Build generated a seeded synthetic dataset of 536 records, labelled synthetic everywhere with no real data used or claimed, with tiers clean 192, exact duplicates 24, near duplicates 24, low-quality poison 288, and contaminated 8, filtered it through the Learn pipeline (exact dedup removed 24 leaving 512, near dedup removed 30 leaving 482, quality filters removed 288 poison records leaving 194, decontamination removed x001 and x005 leaving 192 clean records, 48 per category), and measured a data mixture study with the same multinomial Naive Bayes model (instruction tokens, alpha 1.0) on a held-out synthetic eval set of 80 records: mixture A (raw unfiltered, 536 train records) scored accuracy 0.0 (0 of 80, with cyclic confusion code to factual, factual to language, language to writing, writing to code at 20 each), mixture B (filtered, 192 train records) scored accuracy 1.0 (80 of 80, 20 of 20 per category), delta 1.0, with 8 hand-computed Build tests passing plus 12 Learn tests and the scaffold smoke test and results_build.json byte-identical across two runs at sha256 0d0c4d8b7ec55205c03a9949e09888fc6a0c59e80dd3d8e7e41f5aa02859deb4.

## The contrast, stated before running

The design, the hand-computed stage counts, and the predicted
accuracies were written in BUILD-SPEC.md before the code.

- Mixture A: the raw generated mix, unfiltered, 536 records,
  including every flawed tier.
- Mixture B: the same records after the Learn pipeline (exact
  dedup, near dedup at Jaccard 0.8, quality filters,
  decontamination). 192 records.
- The only difference is filtering. Same generator, model,
  smoothing, and eval set.
- Downstream task (a proxy, named as a proxy): predict the
  category of an instruction with a multinomial Naive Bayes
  classifier over instruction tokens. Metric: accuracy on the
  held-out eval set.

## Generator (seed 42)

Template families over 4 categories (code, factual, language,
writing), each with 2 signal verbs. Clean instructions are
verb, a unique topic token, in, simple, terms (5 tokens), with
per category output templates. Flawed tiers are deliberate:

| Tier | Count | Flaw |
| --- | --- | --- |
| Clean | 192 | none, 48 per category |
| Exact duplicates | 24 | verbatim copies of clean records |
| Near duplicates | 24 | copies plus one token (Jaccard 5 over 6, 0.833) |
| Low-quality poison | 288 | 1 token output (unknown) and a label shifted to the next category |
| Contaminated | 8 | instruction equals a Learn benchmark prompt, 4 copies per prompt |

The raw file is synthetic_data.jsonl (536 records, each record
carries synthetic true, its source, license, and tier). The eval
file is synthetic_eval.jsonl (80 records, topics evaltopicNNN,
never in training).

## Filtering, measured

Measured 2026-11-05, Muse VM, Python 3.12.3, standard library
only. Full record: results_build.json in this folder. Removed
ids per stage are in that file.

| Stage | Left | Removed |
| --- | --- | --- |
| Raw (synthetic) | 536 | - |
| Exact dedup | 512 | 24 exact copies |
| Near dedup (Jaccard 0.8) | 482 | 24 near copies plus 6 contaminated copies |
| Quality filters | 194 | 288 poison records (all of them) |
| Decontamination (2 benchmark prompts) | 192 | x001, x005 |
| Final mixture B | 192 | exactly the clean ids s001 to s192, 48 per category |

## Mixture study, measured

| Mixture | Train records | Eval accuracy | Correct |
| --- | --- | --- | --- |
| A, raw unfiltered | 536 | 0.0 | 0 of 80 |
| B, filtered | 192 | 1.0 | 80 of 80 |
| Delta (B minus A) | -344 | 1.0 | - |

Mixture A per category: 0 of 20 in every category. Its confusion
is fully cyclic, 20 each: code predicted factual, factual
predicted language, language predicted writing, writing
predicted code. Mechanism, predicted in the spec: each signal
verb occurs 30 times under its true label (24 clean plus 3 exact
plus 3 near copies) and 36 times under the poison label, so the
poison label wins every templated eval record. Mixture B per
category: 20 of 20 in every category, because in the filtered
set each signal verb occurs only under its true label.

Interpretation, bounded: on this synthetic stress mix, stub
output records with shifted labels, at a majority share of the
raw data, destroyed the downstream classifier, and the Learn
quality filter removed exactly those records because their
outputs are 1 token. This says nothing about real datasets or
real proportions. The duplicate and contaminated tiers moved
the pipeline counts but had no separate downstream effect in
this design (duplicates only reinforced clean signal;
contaminated tokens do not occur in the eval templates).

## Grade

8,800 of 10,000. Deductions: the template task is separable by
design, so mixture B at 1.0 is a designed outcome, not a
discovery (minus 400); the downstream model is an
instruction-only Naive Bayes proxy, not SFT training of a
language model (minus 300); the poison share (288 of 536) is a
stress proportion, not a natural data mix (minus 200); the eval
set is synthetic with the same templates as training, only the
topic tokens held out (minus 200); the duplicate and
contaminated tiers show no separate downstream effect in this
design, so the study isolates the quality and label flaw only
(minus 100). Total deductions 1,200.
